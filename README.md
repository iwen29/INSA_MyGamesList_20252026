# Projet de Programmation Mobile

Ce projet est une simple application listant les jeux d'une base de données.

## Fonctionnalités

Base :
- Liste des jeux dans la base de données
- Affichage des détails des jeux séparément avec titre, description, plateformes, cover art, et genres
- Filtrage des jeux affichés par recherche
- Mise en favori depuis la liste des jeux ou la page de détails, affichant les jeux favoris en haut de la liste

Bonus :
- Obtention des données par l'API IGDB en fonction de leur note (100 meilleures notes)
- Support du thème sombre
- Liste de favoris persistante
- Possibilité de naviguer entre les pages des jeux (prenant en compte le filtrage)
- Filtrage par tags
